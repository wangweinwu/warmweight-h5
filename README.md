# 宠物精灵 PetMon 🌱

仿宝可梦玩法的 2D 网页宠物养成对战游戏。纯前端、零依赖、零构建，打开即玩。

**▶ 在线玩：Vercel 部署后访问你的域名即可**（见下方部署说明，导入仓库点两下就上线）

## 玩法

- **御三家开局**：草系「芽芽兽」/ 火系「焰尾狐」/ 水系「芡芡龟」三选一
- **大地图探索**：方向键移动，走进草丛随机遭遇野生精灵（共 **13 种**原创精灵，11 系属性）
- **回合制对战**：属性相克（2×/0.5×）、物理/特殊/变化三类技能、会心一击、先制攻击、异常状态（中毒/灼伤/麻痹/冰冻）、能力升降
- **升级学技能**：每只精灵 7~9 个技能的学习表，升级自动学习；技能栏满 4 个时可在队伍面板替换
- **进化**：芽芽兽 Lv.18 → 叶卫兽
- **捕捉**：精灵球/高级球，血越少等级越低越好抓；抓到的精灵入队（最多 6 只）
- **道馆挑战**：石英道馆 3 连战（含馆主），胜者获石英徽章
- **商店/背包/图鉴**：金币经济、5 种道具、13 格图鉴收集
- **存档**：localStorage 自动保存（每 20 秒 + 关键节点），F5 也可手动保存

## 部署到 Vercel

零构建、纯静态，两种方式任选：

**方式 A — 网页导入（推荐）**
1. Push 本仓库到 GitHub
2. 打开 [vercel.com/new](https://vercel.com/new) → Import 选本仓库
3. Framework Preset 选 **Other**（其余默认）→ Deploy，完成

**方式 B — CLI**
```bash
npm i -g vercel
cd petmon
vercel --prod
```

部署后更新游戏只需 `git push`，Vercel 自动重新发布。

## 本地运行

```bash
cd petmon
python3 -m http.server 8000
# 打开 http://localhost:8000
```

或直接双击 `index.html`。

## 技术

- 零依赖 vanilla JS：Canvas 2D 渲染（地图/战斗）、DOM 面板（队伍/背包/商店/图鉴）
- `js/data.js` 种族/技能/学习表数据驱动，改这里即可扩展新精灵
- `js/engine.js` 纯逻辑战斗引擎（可脱离 DOM 单测）
- `js/world.js` 地图与主循环 · `js/battle.js` 战斗 UI · `js/ui.js` 面板与存档 · `js/audio.js` WebAudio 合成 8-bit 音效
- 图片素材：`assets/img_png/`（战斗透明立绘）与 `assets/img/`（图鉴白底）
