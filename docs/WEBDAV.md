# WebDAV 云备份使用指南

> v1.2 新增：把你的全部数据（账号资料、减重计划、体重记录、体型照片）自动备份到**你自己的 WebDAV 网盘**，数据完全归你所有。

## 支持的 WebDAV 服务

| 服务 | 服务器地址 | 密码说明 |
|---|---|---|
| **坚果云**（推荐国内用） | `https://dav.jianguoyun.com/dav/` | 必须用「应用密码」：网页版 → 账户信息 → 安全选项 → 添加应用密码 |
| **Nextcloud / ownCloud** | `https://你的域名/remote.php/dav/` | 账户密码或应用密码 |
| **Alist** | `http://你的地址/dav/` | 挂载时设置的密码 |
| **群晖 / 威联通 NAS** | NAS 的 WebDAV 套件地址 | 设备账号密码 |
| 其他任意 WebDAV | 服务商提供的地址 | — |

## 配置步骤（30 秒）

1. 打开应用 → 底部「**我的**」→「**WebDAV 云备份**」
2. 开关选「**开启**」，填入服务器地址、账号、密码（应用密码）
3. 点「**测试连接**」→ 提示成功后保存
4. 完成。之后每次记录体重/照片，约 8 秒后自动备份到你的网盘

## 工作机制

- **自动备份**：任何数据变更后防抖 8 秒上传整包快照，文件为 `warmweight/warmweight-backup-<用户ID>.json`
- **换机恢复**：新手机登录同一账号后，若云端备份比本地新，自动提示恢复；也可在设置页手动「从云端恢复」
- **与内置云同步的关系**：本地 localStorage 永远是第一优先；WebDAV 是你私有网盘里的**异地备份**，两层互不干扰

## 连接方式怎么选

- **经本站代理（默认）**：无跨域限制，坚果云等所有服务直接可用；需 Vercel 部署（自带 `/api/webdav` 函数）
- **直连**：更快、不经过你的服务器，但要求 WebDAV 服务开放 CORS（Nextcloud/Alist/NAS 可配置）

## 隐私与安全

- 备份文件存在**你自己的网盘账号**里，应用服务器（如有）只做代理转发，不落盘任何数据
- 建议一律使用 WebDAV 服务商提供的「应用密码」，不用主密码
- 快照含照片（压缩后），单个备份约 0.1~2MB，免费网盘额度完全够用

## 自建部署者须知

代理函数 `api/webdav.js` 默认允许转发到任意 http(s) WebDAV 地址。若你的部署是公网共用实例，建议设置环境变量限制转发目标：

```
WEBDAV_PROXY_ORIGIN_ALLOWLIST=dav.jianguoyun.com,dav.example.com
```

个人自用（Vercel 个人实例）无需配置。
